# YUK & CHES'S HOME - Frontend

这是一个基于 HTML, CSS, Vanilla JavaScript 纯前端构建的 UI 项目。
整体设计理念为：“绿意盎然的木质图书馆”。

## 包含的功能页面：
1. **开屏 (Splash Screen):** 带有天气、时钟、纪念日统计和 AI 随机语句，支持上滑/点击进入。
2. **聊天主界面 (Chat Screen):** 图书馆纸质/木质风格，带有绿色的用户气泡和纸白色的AI气泡，支持发送消息和加号功能菜单展开。
3. **记录界面 (Timeline Screen):** MiGi 风格的时间轴，暗色模式。
4. **侧边栏 (Sidebar):** 分类导航，可切换至记账本等界面。
5. **记账界面 (Ledger Screen):** 资产与支出统计展示。
6. **设定界面 (Settings Screen):** AI参数、世界书和记忆系统配置列表。

## 如何运行：
1. 解压本 ZIP 文件。
2. 双击打开 `index.html`，建议在浏览器中按 `F12` 开启移动端（手机）模拟模式查看最佳效果。
3. 可直接部署到 GitHub Pages、Vercel 或 Render。
